# Overview

pastey is a Claude Code skill that automatically opens the human-readable things Claude
produces — spec and plan documents, any artifact written to a readable file, and generated
text meant to be copied elsewhere (SQL queries, command lines) — in the user's editor of
choice, usually VS Code, so the user never has to hunt for them in the terminal. Current
state: project scaffolded; the design has not been brainstormed yet.

## About these docs

Markdown in `docs/` is the source. `docs/site/` and `docs/roadmap.md` are generated by
`uv run scripts/pmdocs.py build` — the pre-commit hook does this for you — and are never
edited by hand. `docs/pmdocs.toml` maps source files to the pages that describe them.
Ad-hoc ideas go in `TODO.md` at the repository root; they are triaged into the backlog.
